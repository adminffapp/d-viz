# FF Döviz

TCMB gösterge kurlarıyla çalışan çevirici, geçmiş kur, karşılaştırma, takip, uyarı ve rapor sitesi.

```
npm install
npm run ornek     # işaretli örnek veri (yalnızca deneme)
npm run uret      # sayfaları üret
npm run dev       # http://localhost:4173 (portu terminalde görürsünüz)
npm test
```
Gerçek veri ve yayın: `docs/04-yayina-alma.md`. Özellik–sayfa eşlemesi: `docs/02-ozellik-kontrol-listesi.md`.
